# Internship Market Analytics

##  Project Overview

This project analyzes internship opportunities in India to understand
market demand, stipend trends, required skills, education requirements,
work modes, locations, and high-paying internship opportunities.

The project uses Python, MySQL, Power BI and potentially Machine Learning.

---

## Objectives

- Analyze internship market trends
- Identify high-demand skills
- Analyze stipend distribution
- Compare stipend across work modes
- Identify major internship locations
- Analyze education requirements
- Identify high-paying internship opportunities
- Build an interactive Power BI dashboard

---

##  Dataset

The dataset contains internship listings with information about:

- Internship title
- Company
- Industry
- Location
- Work mode
- Internship type
- Duration
- Stipend
- Skills
- Education requirements
- Source platform

Dataset size:

- 5,865 internships
- 21,031 skill records
- 6,037 education records
